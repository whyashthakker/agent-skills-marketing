# xquik-research

**A Claude Code skill for planning X data research workflows with Xquik.**

Use `/xquik-research` when the user needs X data for social listening,
creator discovery, competitor monitoring, trend research, or campaign analysis.

## What it produces

- Research brief
- Source and endpoint plan
- Collection scope
- Normalized output schema
- Analysis prompts
- Ethics and approval checks

## Usage

```bash
/xquik-research Monitor launch feedback for our new AI product on X
```

```text
"Find creators discussing developer tools on X"
"Track competitor messaging around an upcoming launch"
"Build a social listening plan for a pricing change"
```
